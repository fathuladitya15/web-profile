Profile Background

Architecting Robust Systems with Real Business Impact

Menggabungkan ketelitian arsitektur database, performa backend tingkat enterprise, serta antarmuka intuitif untuk mendukung kelancaran operasional perusahaan.

Saya adalah Fullstack Developer yang berfokus pada perancangan dan implementasi aplikasi berbasis web skala enterprise.

Keahlian inti saya mencakup pengembangan sistem Human Resource Management (Smart HRM), engine penggajian otomatis (payroll calculation), sistem absensi berbasis GPS & geofencing, arsitektur RESTful API berlatensi rendah, serta deployment berbasis cloud menggunakan Laravel, Vue.js, MySQL, Linux VPS, dan AWS.

Sepanjang perjalanan karier profesional, saya terbiasa memegang siklus penuh pengembangan perangkat lunak (SDLC)—mulai dari analisis kebutuhan bisnis, normalisasi skema basis data, implementasi clean code architecture, integrasi tokenized authentication (JWT & Sanctum), hingga automated CI/CD pipeline dan server tuning.

Selain pengembangan aplikasi web, saya memiliki keunggulan kompetitif dalam integrasi hardware & IoT, seperti menjembatani timbangan digital Bluetooth (BLE) menggunakan Python daemon untuk pemrosesan data penimbangan industri secara real-time langsung ke sistem cloud.

Tantangan & Solusi:

Pabrik PT Sun Wing Ming Indonesia menggunakan mesin fingerprint fisik untuk mendata kehadiran ratusan pekerja shift pabrik. Fitur Utama:

  • Rekonsiliasi otomatis data kehadiran aktual terhadap jadwal shift kerja karyawan pabrik
  • Manajemen pengajuan dan approval berjenjang untuk cuti, izin sakit, dan lembur
  • Payroll Engine manufaktur otomatis (gaji pokok, tunjangan shift, lembur, dan potongan presensi)
